Montre de Vie

Confidentialité

Cette page décrit, de façon aussi précise que possible, ce qui se passe réellement avec les informations que tu saisis dans l'outil — pas une formule type, mais ce qui est vérifiable dans le code du site.

Ce que tu saisis dans l'outil

Le calculateur (/montre/) te demande, selon le mode choisi : âge, sexe biologique, habitudes de vie (tabac, alcool, sommeil, stress, activité physique, alimentation), et en mode Complet des capacités physiques (VO₂max, force de préhension, vitesse de marche) et éventuellement des biomarqueurs sanguins (LDL, glycémie, tension, etc.) que tu peux renseigner si tu les connais.

Le calcul se fait entièrement dans ton navigateur. Les réponses que tu saisis ne sont jamais transmises à un serveur pour produire ton résultat — tout le traitement (espérance de vie, âge biologique, recommandations) est exécuté en JavaScript, localement, sur ton appareil.

Ce qui est sauvegardé, et où

Pour te permettre de revenir sur tes résultats sans tout ressaisir, le site utilise le stockage local de ton navigateur (localStorage) — jamais un serveur :

Donnée sauvegardéeOùPourquoi
Tes réponses au formulaire et ton dernier résultatLocalRetrouver ta session si tu reviens sur la page
L'historique de tes calculs (jusqu'à 12 entrées)LocalAfficher ton évolution dans le temps (graphique)
Le mode choisi (Express / Complet)LocalMémoriser ta préférence
Le déblocage du rapport PDF premium, après paiementLocalNe pas te redemander de payer sur cet appareil

Rien de tout cela ne quitte ton appareil. Tu peux l'effacer à tout moment via le bouton « Effacer l'historique » sur la page de résultats, ou en vidant le stockage local de ton navigateur pour ce site.

Les cas où une information part vers un service tiers

Le site n'a pas de serveur propre qui collecte tes données de santé. Mais comme tout site web, il charge quelques services tiers pour fonctionner. Voici ceux identifiés dans le code :

Ce que le site ne fait pas

Vérifié dans le code du site : aucun outil d'analytics (type Google Analytics), aucun pixel publicitaire (Facebook ou autre), aucune régie publicitaire, aucun compte utilisateur à créer, et aucun cookie n'est posé directement par le code du site lui-même.
